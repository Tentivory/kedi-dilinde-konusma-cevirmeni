# Kedi Dilinde Konuşma Çevirmeni

## Bu Ne Lan?!

Bu proje, insanlığın en büyük sorununu çözmek için tasarlandı: **Kedilerle anlaşamamak**.

Artık Türkçe yazdığınız her şey, bilimsel olarak doğrulanmış (tamamen uydurma) kedi diline çevrilir. Kediler sizi anlar mı? Hayır. Ama siz miyavladığınızı sanırsınız ve bu yeterlidir.

### Özellikler (Abartılı)
- Gerçekten çalışır (Python 3 ile).
- Rastgele miyav uzunlukları üretir.
- Hiçbir şeyi gerçekten çevirmez ama öyle görünür.
- Kedileriniz sizi yargılayacak.
- Gizli bir şey var ama bulamazsınız (ya da bulursunuz).

### Kullanım
```bash
python kedi_cevirmen.py
```
Sonra bir şeyler yazın, ENTER'a basın, miyavlayın.

### Neden Var?
Çünkü neden olmasın? Hayat zaten saçma.
